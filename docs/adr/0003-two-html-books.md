# Two HTML books: an English handbook here, a French learning book elsewhere

Status: accepted

Every change is explained in readable HTML, not only in code and ADRs. Because everything committed here is in English, the material serves two readers through two books. The **handbook** (`docs/handbook/`, English only) is a reference for someone taking over the project: what each part does, how to run it, its limits, and which ADR explains it; it is updated in the same pull request as any behaviour it describes. The **learning book** lives in `chadlis/hypotrail-learning` (French by default, with an English switch): a guided path from each concept to its implementation in Hypotrail and the reason for that choice, written per delivery slice by a fresh-context session from the diff, the notes, the glossary and the ADRs.

## Consequences

- Each book has one source file per chapter, assembled by a standard-library script into one self-contained HTML file; chapters describe the current state and are rewritten when it changes, history stays in ADRs.
- The learning book never restates a decision: it links to code at a pinned commit and to the ADR. The handbook never teaches concepts.
- Every HTML page uses the cosmic-couture charter in light mode by default; step-by-step mechanisms may be animated with the mechanism-explainer approach.
- Study reports generated by the software are English only in lot 1.
