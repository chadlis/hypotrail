The first milestone is accepted test by test. SPEC §10 lists 24 acceptance tests, T01 to T24. This chapter has one row per test with what it does, the result it expects, and either the proof that it holds or an explicit not run with its reason. Three statuses are kept apart, each with its own value and its own evidence, and none derived from another: OFFLINE_ACCEPTED, LIVE_ACCEPTED (conditional: References E01–E10 reviewed by proxy, owner review pending) and USABILITY_REVIEW_PENDING (open).

The three statuses

OFFLINE_ACCEPTED rests on T01 to T19 and T21 to T24 and is computed from the rows of the grid below: it is reached only if each of those rows has a passing proof, and otherwise it is pending and names the rows that hold it back. A row marked not run holds it back. LIVE_ACCEPTED rests on T20 and on the model report of the spike, together with the owner's review of the References, and it is conditional: References E01–E10 reviewed by proxy, owner review pending. The grid's test computes its value: conditional when T20's row has a passing proof, the spike's report is cited as its evidence and the owner's review of the References is pending, and pending otherwise. USABILITY_REVIEW_PENDING stays open until another person has read the README path.

The grid

Each row's English text renders the row of SPEC §10; whether it renders it faithfully is checked by the review of record, not by a test. A pytest proof names test nodes, and each node declares the row (T05 in its name or its docstring): a collected test that is about another row fails the grid. Whether the content of a test matches what §10 asks of the row is not checked by that declaration; it stays with the review of record. A pytest proof passes if its nodes pass in the same suite as the test that reads this table. The T24 row passes when the walk record exists, passes the test that checks it against the README, and holds what T24 expects: the walker identified, a failure and a limit found, the difficulties recorded. A recorded difficulty does not fail it; a difficulty that kept the walker from finding the failure or the limit does.
