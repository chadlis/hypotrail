report renders one HTML page for a Study of the temporal regression Track, from the Study's records alone: the Attempts, Observation sets, Assessments, Comparisons, the freeze record and the Exposure journal. The page holds its text, styles and tables inline, loads nothing, has no script and computes nothing when it is opened. A page that shows public_check Items is an Exposure and is recorded as one.

The command

python -m hypotrail report --study DIR --out FILE, with --json and --examples-dir DIR (the flags are in the commands table of chapter 04). The code is src/hypotrail/report/: gather.py reads and verifies the records, render.py writes the page, command.py is the command. It imports neither Inspect nor scikit-learn nor NumPy (ADR 0001), and it calls no fit, no prediction, no model and no tool, so it works with the network cut.

  1. The Study is read; a Study of another Track is refused (the tool-using agent Track is the next ticket's). --out must not be inside the Study, nor a directory, and its folder must exist.
  2. Every artifact the page shows is read back against its digest: a changed byte is ARTIFACT_INTEGRITY (exit 3) and no page is written.
  3. If the page shows public_check Items, the Study's writer lock is taken (a second writer is STUDY_LOCKED, exit 6), the Workload is found through the one resolver of chapter 04 and its Protocol is checked against the revision's (PROTOCOL_CHANGED, exit 3), the freeze record is written first if the revision has none, then one journal entry names the Attempts, Assessments and Comparisons the page shows of those Items (chapter 12). A Study whose Items are all dev records nothing, takes no lock and reads no Workload.
  4. The page is written to a temporary file beside --out and renamed onto it: an existing file is replaced.

The page is rebuilt from the Study each time it is asked for; it is never stored as a record. Two reports of the same public_check Study record two Exposures.

# a page for a Study; --out is outside the Study
uv run python -m hypotrail report --study runs/bike --out runs/bike-report.html

The sections

The nine sections of the specification, in its order, then the Exposure section. Each has a stable id. The page's own headings, labels and sentences are in English; a string that comes from outside the code (a question, an ID, a declared field) is shown as given, HTML-escaped, in text and in attributes, and a web address in it is text, never a link.

The tenth section is not one of the nine of the specification: the ticket asks for it, and it sits after them so that the nine keep their order.

What the numbers are

Every value is written into the HTML when the page is rendered. The values the records hold (Metrics, counters, deltas, coverage) are read as recorded. Two tables hold values the records do not: the table by month (the Items of the month and the mean of the Assessment's per-Item absolute errors, with the number scored) and the Reasons per Criterion (the per-Item states, counted). Both are computed from the recorded per-Item file when the page is rendered, never when it is opened. The ten largest errors are ranked by absolute error, the larger first and equal errors by Item ID; the difference column is predicted minus true.

A Comparison is shown with its Control and Candidate Assessments, its comparability status and warnings, its coverage and its deltas as recorded. A positive delta means the Candidate is worse. A Comparison against an Import is shown as descriptive, with its warning. An Attempt that is running is shown as running, whether or not its writer is alive, and an interrupted one as interrupted.

What the page does not say

The page never attributes readiness, safety or independence to an output, a Configuration or a Study. The one sentence that names those words denies them; it is listed here so that the test over the page's own text can allow it by its exact text.

Sentence
This report does not state that any output, Configuration or Study is production-ready, safe or independent.

Limits

Bike Studies only

A Study of the tool-using agent Track is refused. Its Case by Repeat matrix, the scripted_fixture banner and the Episode traces are the next ticket's.

A report is an Exposure

Showing public_check outputs is an Exposure even with no Assessment. The entry is written before the page, so a failure to write the page leaves the entry.

No licence text

The Study keeps the dataset, not the licence notice or its attribution addresses: the page names the notice file the Workload declared and shows no notice text.

No in-page links

The only links are relative links to Study artifacts, from the folder of --out, each with its SHA-256. Moving the page without the Study breaks them.
