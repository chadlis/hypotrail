Check whether the numbers in an English draft can be traced to the Study. Give the command a UTF-8 file, or pass --text - to read the draft from standard input.

hypotrail numbers check --study ./bike-study --text draft.txt --json

The check uses aggregate Assessment and Comparison values from the current Study revision on the development Partition. It accepts a number at the precision shown. For example, a recorded mean absolute error of 1090.7912 supports "1,090.79", and "five folds" also counts as a numeric claim. Give --user-text user.txt to allow the draft to repeat numbers from the person's own words, such as a target they supplied.

The JSON has clean: true and an empty findings list when all numbers are traceable. Each untraceable_number finding gives the text of the occurrence and its start and end offsets. The command takes no Study lock, records no Exposure and writes nothing.
